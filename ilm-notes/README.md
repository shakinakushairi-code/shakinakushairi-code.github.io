# Ilm Class Notes

Personal notes from Islamic 'ilm classes, compiled by Shakina Kushairi (SK). Every ayat and hadith is checked against quran.com, sunnah.com and dorar.net.

Live site: https://shakinakushairi-code.github.io/ilm-notes/ (folder within the main site repo, not linked from the business pages)

## Structure
- `index.html`: landing page, one card per class
- `notes/<slug>/index.html`: notes to read online
- `notes/<slug>/*.pdf`: downloadable PDF (SK watermark)

To add a class: create `notes/<slug>/` with `index.html` + PDF, then add a card to `index.html` (newest first).
